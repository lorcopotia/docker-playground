# Como utilizar

1. Modificar el fichero `env.example` con los valores especificos de cada usuario.
2. Renombrar `env.example` a `.env`.
3. Ejecutar `sudo docker compose up`.
4. Configurar npm para acceder a cada contenedor via 443. Para ello crear un certificado SSL en duckdns.org.
5. Enjoy!

# How to use: 

1. Modify the `env.example` file with the specific values ​​for each user.
2. Rename `env.example` to `.env`.
3. Run `sudo docker compose up`.
4. Configure npm to access each container via port 443. To do this, create an SSL certificate at duckdns.org.
5. Enjoy!
